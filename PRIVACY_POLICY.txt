Privacy policy for Memorable: AI Photo Search
Last updated: August 30, 2026

Overview

Memorable processes locally available photo and video contents and search query text on your iPhone. The developer does not operate a backend for the app and does not receive your photos, videos, queries, index, or usage activity.

Data the developer does not collect

Memorable does not include developer-operated data collection. In particular, the app has:

- No developer account or backend service
- No analytics or telemetry
- No user tracking or advertising
- No advertising identifier use
- No third-party data-collection SDK
- No external crash-report upload

The app can write technical diagnostics to the local iOS logging system. The app does not upload those logs, and the developer does not receive them through Memorable.

On-device processing

Memorable uses bundled Core ML models to analyze media and encode search text on your device. It stores generated embeddings, OCR text, scene labels, dates, dimensions, searchable place names, search history, and app settings locally.

During indexing and search, photo and video contents and search query text are not sent to the developer, Apple's reverse-geocoding service, or an AI service. The app disables network access on PhotoKit media requests. As a result, it does not fetch iCloud-only media for indexing. User-initiated sharing, described below, provides one selected photo to the destination you choose.

Apple service traffic

During indexing and commerce, Memorable uses two Apple-managed services that may use network access:

1. Apple reverse geocoding: If indexed media contains GPS metadata, Memorable may send its latitude and longitude coordinates to Apple's MapKit or Core Location reverse-geocoding service. Apple returns place names such as city, state, and country. Memorable stores those place names locally. It does not send the photo or video contents or your search query text with the request.

2. Apple StoreKit: Memorable uses StoreKit for Pro product information, entitlement verification, purchases, restores, refunds, and transaction updates. StoreKit exchanges the account, product, transaction, and device information that Apple requires to provide those services. The developer does not receive photo contents, video contents, search query text, or the local search index through StoreKit.

Photo library access

Memorable requests Photo Library access to index and display media locally. You can limit or revoke this access in iOS Settings.

User-initiated sharing

Memorable displays the iOS share sheet only after you tap Share for a photo. The app copies the locally available image resource without changing its bytes, then provides the copy to the Apple share sheet so you can choose a destination. The file can include the source image's embedded GPS, camera, date, and other metadata. The destination you select may transmit or store the image according to its own behavior and privacy policy. Memorable does not choose a destination, start sharing automatically, or receive the image or destination information through a developer backend. PhotoKit network access remains disabled while Memorable prepares the image.

User-controlled playback

Memorable allows AirPlay when you choose an external playback destination in the system player. Apple and the selected playback destination handle that connection. Picture in Picture continues playback through the local iOS system player. Memorable does not start external playback automatically or send playback data to the developer.

Folder access

If you use Pro to add a folder source, Memorable reads supported images only from the folder you select. It stores a security-scoped bookmark so it can reopen that folder. Bookmark files are protected and excluded from device backup. The app rejects special files, symbolic links, and paths outside the selected folder. It also bounds directory traversal and reads an immutable snapshot of each accepted file before image parsing.

Memorable accepts up to 32 new folder registrations. If an earlier version already saved more folders, Memorable keeps all of them visible so you can remove them. Rebuilding the index preserves folder registrations and bookmarks, then schedules those folders for indexing when Pro is active. A confirmed loss of Pro access removes derived folder index rows but preserves the registrations and bookmarks so they can be indexed again after Pro is restored.

Local storage and deletion

Memorable stores its search database and app state in the app sandbox. The local data directory uses iOS complete-unless-open file protection and is excluded from iCloud and device backups. You can delete the search index in the app. Uninstalling Memorable removes the app's locally stored data according to iOS behavior.

Children's privacy

The developer does not collect personal data from users, including children.

Policy changes

An app update will include any material change to this policy.

Contact

For privacy questions, use the support page listed on the App Store product page.
